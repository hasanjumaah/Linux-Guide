إدارة الملفات والمجلدات والنصوص

الأمرالوظيفة
pwdمعرفة مسار المجلد الحالي (Print Working Directory).
ls -lahعرض الملفات بالتفصيل مع إظهار الأحجام بصيغة مقروءة (MB, GB).
cd ~العودة مباشرة إلى مجلد المستخدم الرئيسي (Home).
mkdir -p dir1/dir2إنشاء شجرة مجلدات متداخلة بضغطة واحدة.
touch file.txtإنشاء ملف نصي فارغ.
cp -r src/ dest/نسخ مجلد كامل بكافة محتوياته (-r يعني Recursive).
mv old.txt new.txtإعادة تسمية ملف أو نقله لمسار آخر.
rm -rf /pathحذف مجلد وملفاته نهائياً وبدون تأكيد (خطر!).
cat file.txtقراءة محتوى الملف وعرضه بالشاشة.
head -n 10 fileعرض أول 10 أسطر فقط من الملف.
tail -f /var/log/syslogمراقبة التحديثات على ملف السجلات (Log) بشكل حي.
grep "error" log.txtالبحث عن كلمة "error" بداخل الملف النصي.
find / -name "app*"البحث في كامل النظام عن أي ملف يبدأ اسمه بـ app.
tar -czvf arc.tar.gz dir/ضغط مجلد وتحويله إلى ملف مضغوط (tar.gz).
chmod 755 script.shتغيير صلاحيات الملف لإعطاء إذن التنفيذ.
chown root file.txtتغيير مالك الملف إلى المستخدم الجذر (root).

مراقبة النظام وإدارة الموارد

الأمرالوظيفة
topمراقب النظام الكلاسيكي لعرض العمليات واستهلاك الموارد.
htopنسخة تفاعلية وملونة لإدارة العمليات (تتطلب تنصيب).
ps aux | grep nginxالبحث عن عملية معينة (مثل nginx) وتفاصيلها.
kill -9 [PID]إيقاف عملية معلقة قسرياً باستخدام المعرف الخاص بها.
killall firefoxإغلاق جميع العمليات التابعة لبرنامج معين بالاسم.
free -hعرض استهلاك الرام (RAM) بصيغة مقروءة وسهلة.
df -hعرض مساحة التخزين المتبقية والمستهلكة في الأقراص الصلبة.
du -sh /folderحساب حجم مجلد معين بشكل دقيق.
uptimeمعرفة المدة الزمنية لتشغيل النظام بشكل متواصل.
uname -aعرض تفاصيل النظام ونواة لينكس بالكامل.
lscpuعرض معمارية المعالج وعدد الأنوية.
lsblkعرض الأقراص الصلبة المربوطة وتقسيماتها (Partitions).
dmesgعرض رسائل النواة (Kernel) للبحث عن أخطاء العتاد (Hardware).
systemctl status sshdمعرفة حالة خدمة معينة في النظام (تعمل أو متوقفة).

الشبكات والاتصالات

الأمرالوظيفة
ip aعرض عناوين الـ IP الخاصة بكروت الشبكة.
ping 8.8.8.8اختبار الاتصال بالإنترنت مع سيرفرات جوجل.
netstat -tulpnعرض جميع المنافذ (Ports) المفتوحة في الجهاز.
ss -tulnأداة حديثة وأسرع من netstat لعرض المنافذ.
ssh user@192.x.x.xالدخول والتحكم الآمن بسيرفر لينكس بعيد.
scp file.txt user@ip:/pathنقل ملف من جهازك إلى السيرفر البعيد بأمان.
curl -I google.comجلب استجابة السيرفر (HTTP Headers) لموقع معين.
wget [URL]تحميل الملفات المباشرة من الإنترنت عبر سطر الأوامر.
traceroute google.comتتبع مسار الاتصال من جهازك إلى السيرفر المطلوب.
nmcli device showأمر خاص بإدارة الشبكات والواي فاي.

إدارة المستخدمين والصلاحيات

الأمرالوظيفة
whoamiعرض اسم المستخدم المسجل دخوله حالياً.
wمعرفة من هم المستخدمون المتصلون بالنظام وماذا يفعلون.
sudo [cmd]إعطاء صلاحية المدير (Root) لتنفيذ أمر معين.
useradd -m ahmedإنشاء مستخدم جديد مع إنشاء مجلد Home خاص به.
usermod -aG wheel ahmedإضافة المستخدم لمجموعة معينة (مثلاً إعطاؤه صلاحية sudo).
userdel -r ahmedحذف المستخدم ومسح جميع ملفاته نهائياً.
passwd ahmedتعيين أو تغيير الباسورد للمستخدم.
groupsعرض المجموعات التي ينتمي إليها المستخدم الحالي.
su - rootالتبديل إلى حساب المستخدم الجذر (Root).

إدارة الحزم المتقدمة (Fedora DNF)

الأمرالوظيفة
sudo dnf updateالبحث عن تحديثات النظام والبرامج وتنصيبها.
sudo dnf install vimتنصيب حزمة أو برنامج معين.
sudo dnf remove vimإزالة برنامج من النظام.
sudo dnf autoremoveحذف الحزم الاعتمادية التي لم يعد النظام بحاجة إليها.
dnf search web serverالبحث عن برامج في المستودع بكلمات مفتاحية.
dnf info nginxعرض معلومات وتفاصيل كاملة عن حزمة قبل تنصيبها.
dnf list installedعرض قائمة بجميع البرامج المنصبة على جهازك.
sudo dnf clean allحذف الكاش (Cache) لتوفير المساحة وتصليح أخطاء التحديث.
dnf historyعرض سجل التحديثات والتنصيبات للرجوع إليها إن حصل خطأ.
sudo dnf system-upgradeترقية نظام بالكامل إلى إصدار أحدث.
